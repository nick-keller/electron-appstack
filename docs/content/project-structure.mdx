## Processes

Electron apps run code in several processes:

- **Main** – runs in Node.js, creates windows and has full system access. It owns
  the database, the config file and the auto updater.
- **Preload** – runs before the page loads. In this template it only exposes the
  tRPC bridge.
- **Renderer** – runs your React UI in a sandboxed Chromium page, without access
  to Node.js. It talks to the main process only through [tRPC](/doc/ipc).

Code needed by both sides (zod schemas, types, translations) lives in
`src/shared/`.

## Import aliases

| Alias         | Points to           | Available in              |
| ------------- | ------------------- | ------------------------- |
| `@renderer/*` | `src/renderer/src/` | Renderer                  |
| `@shared/*`   | `src/shared/`       | Main, preload, renderer   |
| `@main/*`     | `src/main/`         | Renderer, **types only**  |

The renderer imports the type of the tRPC router from `@main/trpc/router`, which
is why `tsconfig.web.json` also includes `src/main`. Importing a value from
`@main` in the renderer would fail at runtime.
