# Add a route

1. Create a file in `src/renderer/src/routes/`:
   - `help.tsx` → `/help`
   - `notes/index.tsx` → `/notes`, `notes/$noteId.tsx` → `/notes/:noteId`
   - `notes/route.tsx` → layout for `/notes/*` (render `<Outlet />`)
2. Start from this template (the file path string is filled in by the router plugin when `npm run dev` runs):

   ```tsx
   import { trpc } from '@renderer/lib/trpc'
   import { useSuspenseQuery } from '@tanstack/react-query'
   import { createFileRoute } from '@tanstack/react-router'
   import { useTranslation } from 'react-i18next'

   export const Route = createFileRoute('/help')({
     // Optional: preload data before rendering
     loader: ({ context }) => context.queryClient.ensureQueryData(trpc.app.info.queryOptions()),
     component: Help
   })

   function Help() {
     const { t } = useTranslation()
     const { data } = useSuspenseQuery(trpc.app.info.queryOptions())
     return <h1>{t('help.title')}</h1>
   }
   ```

3. `src/renderer/src/routeTree.gen.ts` is regenerated by the Vite plugin during `npm run dev` or
   `npm run build`. Never edit it, but commit it.
4. Link with `<Link to="/help">`, navigate with `useNavigate()`. The app uses hash history
   (URLs look like `index.html#/help`), required for `file://` in production.
5. Add a link in the navigation in `routes/__root.tsx` and translations for the new strings.
6. A route shown in its own window, without the navigation (like `activate.tsx` and `about.tsx`), sets
   `staticData: { standalone: true }`; the main process opens it with `createWindow('/route', …)` in
   `src/main/window.ts`.
